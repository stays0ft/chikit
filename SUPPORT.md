# Support

- Something not working? Start with [docs/TROUBLESHOOTING.md](docs/TROUBLESHOOTING.md).
- Questions about what a permission is for: [docs/PERMISSIONS.md](docs/PERMISSIONS.md).
- A bug or a request: open an [issue](https://github.com/stays0ft/chikit/issues/new/choose).
- A security problem: see [SECURITY.md](SECURITY.md) and report it privately.

This is a one-person project. There is no guaranteed response time, but issues are read.
